# 科目A型問題集

すべて本書オリジナルです。IPA公式サンプル問題の文章・選択肢は転載していません。まず問題だけを解き、後半の解答で全選択肢の理由を確認してください。

## 問題

### 第1章：データマネジメント

**問1** データマネジメントの説明として最も適切なものはどれですか。

1. データベース製品の性能を最大化する技術活動である。
2. データを価値創出へ使えるよう、方針・役割・品質・技術を継続的に管理する活動である。
3. すべてのデータを一つのシステムへ物理的に集約する活動である。
4. 分析担当者だけが分析用データを整形する活動である。

**問2** 営業部の「顧客数」と経理部の「顧客数」が一致しません。最初の対応として最も適切なものはどれですか。

1. 件数が多い方を正しい値として採用する。
2. 更新時刻が新しい方を常に採用する。
3. 対象範囲、粒度、基準日、除外条件、責任者を確認する。
4. 二つの値の平均を全社値とする。

### 第2章：データライフサイクル

**問3** データの廃棄を設計時から検討する主な理由として最も適切なものはどれですか。

1. 保存装置の容量だけを節約するため。
2. 保存期限、複製、バックアップ、法的保留を含めて確実に管理するため。
3. 生成直後のデータは価値がないため。
4. 廃棄すればアクセス制御が不要になるため。

**問4** 同じ顧客CSVがメール、個人PC、共有フォルダに複製されています。最も重要な問題はどれですか。

1. CSVは表計算ソフトで開けること。
2. ファイル名が短いこと。
3. 正本、最新版、権限、保存期限、廃棄対象を一貫して管理しにくいこと。
4. 共有フォルダの表示色が統一されていないこと。

### 第3章：データガバナンス

**問5** ガバナンスとマネジメントの関係として最も適切なものはどれですか。

1. ガバナンスは方針・権限・監視を定め、マネジメントは方針に沿って計画・実行・改善する。
2. ガバナンスは日次入力を担当し、マネジメントは法律を制定する。
3. ガバナンスとマネジメントは常に同一人物が担当する。
4. ガバナンスはIT部門だけ、マネジメントは事業部門だけが行う。

**問6** 商品コードの業務上の意味を最終決定する役割として通常最も適切なのはどれですか。

1. ストレージ管理者
2. 商品データのデータオーナー
3. BIツールの利用者
4. 外部監査人

### 第4章：データ品質

**問7** 必須値充足率を測る式として最も適切なものはどれですか。

1. NULL件数 ÷ 全件数
2. 必須値が入力された対象件数 ÷ 対象件数
3. ユニーク値数 ÷ NULL件数
4. 全件数 ÷ 更新回数

**問8** 売上金額に通常の100倍の値が1件ありました。最も適切な対応はどれですか。

1. 外れ値なので自動的に削除する。
2. 平均値へ置換し、処理記録は残さない。
3. 元伝票、単位、通貨、入力履歴を確認して、正当値か異常値かを判断する。
4. 分析結果に影響しないと仮定する。

### 第5章：メタデータ

**問9** ビジネスメタデータの例として最も適切なものはどれですか。

1. 売上高の業務上の定義と計上ルール
2. データベースのCPU使用率
3. テーブルの物理格納先
4. バックアップジョブの終了時刻

**問10** データカタログ導入後もデータを正しく探せない主な原因として最も適切なものはどれですか。

1. カタログを導入すればメタデータは自動的に正しくなるため、原因はない。
2. 業務用語、責任者、利用条件、更新プロセスが整備・維持されていない。
3. すべてのデータを削除していない。
4. カタログの画面色が部門ごとに異なる。

### 第6章：モデルと統合

**問11** 二つのシステムで顧客IDがいずれも主キーです。そのまま結合できるとは限らない理由はどれですか。

1. 主キーは文字列にできないため。
2. 各システム内の一意性しか保証せず、識別範囲や発番ルールが異なる可能性があるため。
3. 主キーにはNULLが必須だから。
4. 結合には必ず顧客名だけを使うため。

**問12** 注文1件に明細3行、配送記録2行があります。注文IDだけで明細と配送を結合したときの行数は何行ですか。

1. 2行
2. 3行
3. 5行
4. 6行

### 第7章：セキュリティ・法務・倫理

**問13** 権限のある担当者が、承認された目的を超えて顧客データを閲覧しました。主に損なわれたものはどれですか。

1. 機密性
2. 完全性
3. 可用性
4. 圧縮率

**問14** 公開Webページのデータ利用について最も適切な説明はどれですか。

1. 公開されていれば、必ず自由に再配布・AI学習できる。
2. 公開されていれば、個人情報や契約の検討は不要である。
3. 公開の事実だけでは、著作権、利用規約、個人情報等の検討が不要になるわけではない。
4. URLを記載すれば、いかなる複製も許される。

### 第8章：AI・非構造化データ

**問15** 機密文書を外部生成AIへ入力する前に行うべきこととして最も適切なものはどれですか。

1. PoCならルールを無視して入力する。
2. 組織のAI利用ルール、契約、保存・学習条件、承認済み環境を確認する。
3. ファイル名だけ変更して入力する。
4. 出力を削除できるなら入力データの扱いは確認しない。

**問16** 非構造化データの探索性を高める取組として最も適切なものはどれですか。

1. 各自が好きな場所と名前で保存する。
2. 版番号を消し、常に上書きする。
3. 管理場所、命名、分類、タグ、版、責任者を組織ルールに沿って管理する。
4. すべて画像として保存する。

### 第9章：データ基盤・分析

**問17** データレイク、DWH、データマートの選択について最も適切な説明はどれですか。

1. 常にデータレイクが最も優れている。
2. 常にDWHへ全データを格納する。
3. 目的、形式、鮮度、品質、権限、費用、運用能力に応じて組み合わせる。
4. データマートは全社の正本データだけを管理する。

**問18** 広告費と売上に強い正の相関がありました。最も適切な解釈はどれですか。

1. 広告が売上増加の原因だと証明された。
2. 関係は観測されたが、交絡、逆因果、偶然を追加検討する必要がある。
3. 相関があればデータ品質の確認は不要である。
4. 売上を増やすには広告費を無制限に増やせばよい。

### 第10章：意思決定・改善

**問19** 分析結果から対応案を選ぶ際の観点として最も適切な組合せはどれですか。

1. 提案者の役職だけ
2. 重要度、緊急度、期待効果、実現可能性、リスク
3. グラフの色数だけ
4. データ件数の多さだけ

**問20** 施策実施後の検証として不適切なものはどれですか。

1. 目標値と実績値を比較する。
2. 差異要因と副作用を調べる。
3. 期待と異なる結果を記録から除外する。
4. 新たな課題を次の改善へつなげる。

### 第11章：組織文化・協働

**問21** データ活用文化の醸成に有効な取組として最も適切なものはどれですか。

1. 成功事例だけを共有し、失敗を隠す。
2. データの意味や限界を議論せず、ツールの利用数だけを増やす。
3. 成功・失敗から得た知見を共有し、役割や制約の異なる部門が対話する。
4. データ活用を専門部署だけの仕事にする。

**問22** 複数部門のデータ共有を進める際、最初に行うべきこととして最も適切なものはどれですか。

1. 全権限を全社員に付与する。
2. 各部門の目的、必要データ、セキュリティ、作業負担、責任分担を確認する。
3. 既存ルールをすべて廃止する。
4. 利用者へ知らせずデータを統合する。

### 第12章：技術動向・PoC

**問23** PoCの成功条件として最も適切なものはどれですか。

1. 新技術を一度起動できたこと。
2. 担当者が便利だと感じたことだけ。
3. 対象課題、仮説、指標、合格基準、期間、対象データ、停止条件が事前に定義されていること。
4. 本番と同じ全データを最初から無制限に使うこと。

**問24** PoC後の提案に含めるべき情報として最も適切な組合せはどれですか。

1. 良かった結果だけ
2. 効果、前提、未解決課題、リスク、必要体制、コスト、スケジュール
3. 製品名と画面写真だけ
4. 実施者の感想だけ

## 解答・解説

| 1 | 2 | データマネジメントは製品導入や分析前処理だけではなく、価値とリスクを継続的に管理する組織活動です。1・3・4はいずれも範囲を狭く捉えています。 |
| 2 | 3 | 同じ名称でも定義が異なることがあります。1・2・4は差異の理由を確認せず値を決めています。 |
| 3 | 2 | 廃棄は容量削減だけでなく、保持義務、複製、バックアップ、保留を含む管理です。1は目的を狭め、3・4は誤りです。 |
| 4 | 3 | 散在により正本・最新版・権限・廃棄の統制が困難になります。1・2・4は本質的問題ではありません。 |
| 5 | 1 | ガバナンスは評価・方針／指示・監視、マネジメントは具体的な計画・実行・改善を担います。2〜4は役割を固定・混同しています。 |
| 6 | 2 | 業務定義の決定責任は通常データオーナーにあります。ITは実装を支援しますが単独で意味を決めません。 |
| 7 | 2 | 完全性を「必要な値が満たされた割合」として測る例です。1は欠損率であり、3・4は完全性の式になりません。 |
| 8 | 3 | 外れ値は正当な事象かもしれません。根拠を照合してから修正・除外を判断し、記録を残します。 |
| 9 | 1 | 業務上の意味・計上ルールはビジネスメタデータです。2・4は運用、3は技術寄りのメタデータです。 |
| 10 | 2 | ツール導入だけでは、業務定義と更新責任は整いません。1は自動化を過信し、3・4は解決になりません。 |
| 11 | 2 | 主キーはそのシステムの表内での一意性です。全社共通の識別を保証しません。1・3・4は誤りです。 |
| 12 | 4 | 多対多の組合せにより3×2＝6行になります。集計時は先に粒度を合わせる等の対策が必要です。 |
| 13 | 1 | 許可されない閲覧・利用は機密性の問題です。完全性は改ざん、可用性は必要時の利用可能性に関係します。 |

| 15 | 2 | 入力前に組織ルールと処理条件を確認します。PoCやファイル名変更は統制を不要にしません。 |
| 16 | 3 | 非構造化データも管理場所、命名、タグ、版、責任を揃えることで探索・再利用しやすくなります。 |
| 17 | 3 | 基盤要素は目的に応じて使い分けます。1・2は絶対視し、4はデータマートの一般的な用途と異なります。 |
| 18 | 2 | 相関だけでは因果を証明できません。1・3・4は前提と限界を無視しています。 |
| 19 | 2 | 対応案は業務上の優先度、効果、実現性、リスクを比較します。1・3・4は単独では判断根拠になりません。 |
| 20 | 3 | 不都合な結果も改善の重要な証拠です。1・2・4は検証と継続改善に必要です。 |
| 21 | 3 | 経験と失敗を共有し、部門横断で対話することが文化形成につながります。1・2・4は学習と協働を妨げます。 |
| 22 | 2 | 共有前に目的・制約・負担・責任を整理します。1・3・4は過剰権限や無統制を招きます。 |
| 23 | 3 | PoCは検証可能な条件と判断基準を事前に置きます。1・2は主観的・限定的で、4はリスクが高すぎます。 |
| 24 | 2 | 導入判断には効果だけでなく前提、課題、リスク、資源、計画が必要です。1・3・4では判断材料が不足します。 |

## 採点と復習

- 20〜24問正解：各章のケース演習へ進む。
- 15〜19問正解：誤答分野の章末問題を解き直す。
- 14問以下：学習ロードマップの基礎ルートに戻り、用語だけでなく判断理由を説明できるようにする。

正解番号の暗記ではなく、誤りの選択肢が「目的を狭く捉える」「責任を混同する」「前提確認を飛ばす」「暫定対応を恒久対策とみなす」のどれに当たるかを説明してください。
