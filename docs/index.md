# はじめに

本書は、データを専門に管理する技術者だけではなく、**組織のルールに従ってデータを扱い、業務上の意思決定と価値創出に結びつけるビジネスパーソン**を主な読者とします。

## この試験で問われるもの

シラバス案は、科目Aを「目標とする知識」、科目Bを「目標とする技能」として整理しています。したがって、学習では次の二つを分けずに結び付ける必要があります。

- **知識**：データガバナンス、品質、メタデータ、データ基盤、分析、AI、セキュリティ、法務などの意味を理解する。
- **技能**：業務場面で、定義を確認し、問題を発見し、責任主体へ報告し、暫定対応と恒久対応を区別して判断する。

科目Bの公式サンプル問題では、単なる用語暗記ではなく、与えられた組織ルールとデータの状態を読み、責任主体や根本課題、現実的な対応を選ぶ能力が示されています。

## 本書の使い方

1. [学習ロードマップ](guide/roadmap.md)で全体像を確認する。
2. 第1部でデータマネジメントの目的とライフサイクルを理解する。
3. 第2部でデータを安全・正確・説明可能に保つ方法を学ぶ。
4. 第3部で分析、意思決定、組織文化、PoCへ進む。
5. 各章の確認問題と[科目B演習](exercises/subject-b.md)で判断手順を練習する。
6. [科目A型問題集](exercises/subject-a.md)で知識と誤答理由を確認する。
7. [シラバスカバレッジ](guide/coverage.md)で未掲載領域を確認する。
8. 不明語は[用語集](glossary.md)で確認する。
