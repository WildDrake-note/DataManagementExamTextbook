# 用語集

> 定義は本書での学習用要約です。厳密な定義が必要な場合は、各章と一次資料を確認してください。

**AIエージェント**
: 目標に向けて情報取得やツール利用などの処理を自律的に組み合わせるAIシステム。自律性に応じた人間の関与とガードレールが必要になる。

**BI（Business Intelligence）**
: データを集計・可視化し、業務上の判断を支援する考え方やツール。

**CDO（Chief Data Officer／最高データ責任者）**
: 組織全体のデータ戦略やガバナンスを統括する役割。組織により権限と名称は異なる。

**DMO（Data Management Office）**
: データマネジメントの方針、標準、支援、監視などを担う組織機能。

**ELT**
: データを抽出し、先に格納先へロードしてから変換する処理順序。

**ETL**
: データを抽出（Extract）、変換（Transform）、格納（Load）する処理。

**SSOT（Single Source of Truth）**
: ある情報について信頼すべき基準となる一貫した情報源を定める考え方。

**データオーナー**
: 対象データの定義、品質、利用条件などについて説明責任・意思決定責任を担う役割。実際の作業担当者やシステム管理者と同一とは限らない。

**データカタログ**
: 組織内外のデータを探索し、意味、所在、所有者、品質、利用条件などを確認するための仕組み。

**データガバナンス**
: データに関する意思決定権、方針、責任、監視の仕組みを定め、望ましい取扱いを実現すること。

**データスチュワード**
: 定められた方針の下で、定義や品質、メタデータなどの実務的な維持管理を担う役割。

**データプロファイリング**
: 件数、NULL、重複、値の分布、形式などを調べ、データの実態と品質を把握する活動。

**データリネージ**
: データがどこで生成され、どの処理を経て、どこへ提供されたかという来歴・流れ。

**ビジネスグロッサリー**
: 組織で用いる業務用語の意味、同義語、責任者などを統一的に管理する用語集。

**マスターデータ**
: 顧客、商品、組織など、複数業務で共通して参照される基礎的なデータ。

**メタデータ**
: データの意味、形式、生成日時、所有者、利用条件など「データについてのデータ」。

**名寄せ**
: 表記ゆれや識別子の違いがある複数レコードについて、同一対象かを判定して対応付ける処理。

**粒度**
: データが表す対象や集計単位の細かさ。顧客単位と世帯単位、日次と月次などの違いがある。

**PoC（Proof of Concept／概念実証）**
: 技術やアイデアが対象課題に有効かを、限定した範囲と条件で検証する取組。
