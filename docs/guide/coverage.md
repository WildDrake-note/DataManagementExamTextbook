# シラバスカバレッジ

基準はIPA「データマネジメント試験（仮称）シラバス（案）Ver.0.1」です。対応章があるだけで「完成」とせず、本文・演習の状態を分けて管理します。

状態は次の三段階です。

- **掲載**：基礎説明と確認問題がある
- **部分掲載**：基礎説明はあるが、用語例又は演習が不足している
- **未掲載**：独立した説明がまだない

## 更新方法

1. IPAの案内ページで新しい版を確認する。
2. 旧版と新版を項目単位で比較する。
3. 本表の状態、対応章、演習を更新する。
4. 変更理由を `CHANGELOG.md` に記録する。
5. 未掲載又は部分掲載をGitHub Issueへ切り出す。
