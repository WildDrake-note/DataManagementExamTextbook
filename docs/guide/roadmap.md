# 学習ロードマップ

## 1. 推奨順序

| 段階 | 学ぶ内容 | 到達目標 |
|---|---|---|
| 1 | データマネジメント、ライフサイクル | データを資産として扱う理由と、生成から廃棄までの流れを説明できる |
| 2 | ガバナンス、品質、メタデータ | 責任主体を特定し、品質問題を発見・報告できる |
| 3 | モデル、統合、セキュリティ、法務 | 複数データを安全に組み合わせる際の制約を判断できる |
| 4 | AI、非構造化データ | AI入力と文書・画像などの取扱い上のリスクを判断できる |
| 5 | データ基盤、分析、意思決定 | 課題から仮説を立て、適切なデータと分析方法を選べる |
| 6 | 組織文化、PoC | 関係者と協働し、小規模検証を意思決定材料にできる |
| 7 | 科目B演習 | ルール・事実・責任・対応を分けて事例を読める |

## 2. 科目Aの学び方

用語を単独で暗記せず、次の組で整理します。

- **目的**：なぜ必要か
- **対象**：何を管理するか
- **役割**：誰が責任を持つか
- **活動**：何をするか
- **リスク**：怠ると何が起きるか
- **関連概念**：似た語とどう違うか

例として、データカタログは単なる検索ツールではありません。データの意味、所有者、利用条件、品質、所在などを利用者へ届ける仕組みです。登録内容が古ければ、ツールが存在しても適切なデータ活用はできません。

## 3. 科目Bの読み方

事例を次の順で表に整理します。

1. **目的**：何のためのデータ活用か。
2. **規範**：社内ルール、法令、契約、データ定義は何か。
3. **事実**：実データや運用で何が起きているか。
4. **差異**：規範と事実のずれは何か。
5. **影響**：誤集計、漏えい、誤判断など何が起こるか。
6. **責任主体**：データオーナー、利用部門、DMO、IT部門の誰が担うか。
7. **対応**：暫定対応と恒久対応を分ける。
8. **記録・共有**：判断条件と結果を再利用可能にする。

## 4. 初版での優先度

公式サンプル問題に現れた次の領域を優先します。

- データガバナンスの目的
- データオーナーシップと役割分担
- データ品質の予防・発見・改善
- ビジネス／テクニカル／オペレーショナルメタデータ
- データカタログとビジネスグロッサリー
- 異なるデータの識別子、粒度、形式、NULLの確認
- 表面的な技術課題と根本的なガバナンス課題の切り分け
