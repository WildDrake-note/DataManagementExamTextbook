# データマネジメント試験（仮称）教科書

2027年度から開始予定のIPA「データマネジメント試験（仮称）」に向けた、オープンな日本語教科書です。

> [!IMPORTANT]
> 本書はIPA公式教材ではありません。基礎資料であるシラバスは **Ver.0.1（案）** であり、試験名称・範囲・制度は変更される可能性があります。受験時は必ず[IPAの最新情報](https://www.ipa.go.jp/shiken/)を確認してください。

## 現在の状態

初版では、公式シラバス全体を学習単位に分解し、サンプル問題で重視されたデータガバナンス、データ品質、メタデータ、責任分担、データ統合を優先して解説しています。未執筆・要検討事項はGitHub Issuesで管理します。

## 方針

- 公式資料を一次情報とし、外部資料は補助資料として扱う
- 公式資料の記述と本書独自の説明・演習を区別する
- 公式問題を転載せず、必要最小限の要約と参照リンクにとどめる
- 実務担当者が「用語を知る」だけでなく「状況を判断する」力を身につけられる構成にする
- シラバス改訂時に追跡できるよう、章とシラバス項目の対応を明示する
